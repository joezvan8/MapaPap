# MapaPap

## Description
MapaPap is a simple project by your favorite 
WizVan duo to test using React and building
full stack applications. 


## Features
MapaPap currently has to be run locally.
Backend features unavailable as they require API key & injection (dotenvx run -- python app.py).
It allows for searching for places using 
keyword search and then returning the results
on screen. For the purpose of demonstrating the 
backend side, any result stored in the database 
are also concatenated.


## Installation
Inside a terminal, run the following: git clone https://github.com/joezvan8/MapaPap cd backend pip install requirements.txt python3 app.py cd ../frontend npm install npm run dev
<br>***NOTE*** Skip running app.py as this will likely not work locally
